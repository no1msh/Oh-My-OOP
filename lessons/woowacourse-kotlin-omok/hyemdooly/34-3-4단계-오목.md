### 5. DB Helper 의 *도메인 어휘 가져도 된다* — 호두 역방향 변주

라코의 *"오목 데이터베이스 헬퍼이기 때문에 오목 도메인을 가져도 된다"* 어휘 = *명명 자체가 도메인 어휘 보유 정당화*. 호두/103 의 *StoneConverter Object 분리 (Activity 가 StoneEntity 모름)* 결의 *역방향 변주* — 호두는 *도메인 vs DB 어휘 분리 (Converter)*, 둘리는 *Helper 이름 자체가 도메인이라 흡수*.

### 6. EventListener 비대칭 + UI 비즈니스 침투 = 콘솔 어휘의 잘못된 이식

### 7. *raw 만 주고받기 → 외부 수정 부담* (변경 시나리오)

라코의 *"디비에 넣는 값이 변경되거나 스펙이 수정되면 코드를 외부에서 수정하는 상황"* 어휘 = *변경 시나리오 어휘*. *raw 어휘 (Int row, Int col)* 만 주고받으면 *DB 스펙 변경 시 외부 호출자가 변경 흡수*.
