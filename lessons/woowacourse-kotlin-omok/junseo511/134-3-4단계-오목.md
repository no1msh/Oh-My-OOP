### 2. *Rules.forEach → Rule 묶음도 하나의 Rule* 자가 학습

라코 (OmokGame.kt):

PR #104 의 *Rule 인터페이스 의의* 가 *3·4단계에서 Composite 로 발전*. *호출자 코드의 분기 없음* = *추상의 가치*.

블랙잭 INSIGHTS 3 (State sealed) 의 *Composite 변주* — *컬렉션도 한 원소처럼 다룸*. m6z1/113 의 *상태 패턴 활용도 떨어짐 (외부 분기)* 의 *대비쌍* — *외부에서 분기 vs 내부에서 처리*.

## 도메인 특수 어휘 (3·4단계 공백 — Android + SQLite + 학습 욕심)

- **Repository (interface) + OmokRepository (impl)**: 인터페이스 추상 + DI. 변경 시나리오 기반 추상화 자가 도달.
- **CompositeRule (rules.forEach → rule.perform)**: 라코의 *Rule 묶음도 하나의 Rule* 어휘 학습.
- **savedTurn (firstTurn 에서 변경)**: 복원 의도 명시 자가 학습.
- **OmokGame.restart()**: 같은 인스턴스 상태 변경 — 현실 메타포 (바둑판 사오지 않음) 정당화. 라코의 *omokGame 인스턴스 관리* 의문.
- **PlayerStone.color**: Tell-Don't-Ask — *어떤 돌인지 정보 다 담겨있음*.
- **lifecycleScope / 코루틴 / 뷰모델 / 리사이클러뷰**: 학습 단계 외 주제 (라코 회피). 공백의 학습 욕심 토픽.
- **binding.board.xxx 접근 일관성**: m6z1/139 의 findViewById 캐싱 결의 일관성 차원.
- **DbHelper.onDowngrade → onUpgrade 호출**: 공식 문서 패턴. 공백이 *해당 페이지 조사* 어휘.
- **방 만들기 (Room) + RecyclerView**: 4 단계 선택 요구사항. 라코의 *4 단계 선택 요구사항이 더 좋은 경험* 어휘.
- **객체지향 생활 체조 인스턴스 변수 3 개 제약**: 라코의 *체조 규칙 적용 강제 회피* 어휘.
- **OmokGameService**: 도메인 서비스 (4 단계 도메인 분리 시도). 라코의 *Activity 가 DAO 알아야 하나* 어휘 결.
