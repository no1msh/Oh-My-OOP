## 도메인 특수 어휘 (1·2단계 공백 한정)

- **Intersection (교차점)**: 바둑판 격자 교차 좌표. *Point/Position* 명명 모호 → 도메인 어휘 자가 제안.
- **StoneColor (BLACK/WHITE) + PointState (EMPTY/BLACK/WHITE)**: 색 중복 자가 토론. 세 안 (Stone? / StoneColor NONE / 분리) 트레이드오프 narrate.
- **OmokBoard (value class) + Map<Position, Intersection>**: backing property + toMap 으로 외부 가변 차단 정당화.
- **PlayingBoard ↔ OmokGame**: 분리 의미 의문 (코드량 분리 vs 책임 분리).
- **Rule (PlaceRule + JudgeRule + DrawRule)**: 인터페이스 묶음 → 강제 캐스팅 함정. PR #134 에서 *Rule 묶음도 하나의 Rule* 결로 다시 다뤄짐.
- **OmokGame.run() 결과 반환**: *룰 책임 폭증* 자가 자각 → *게임 흐름은 OmokGame* 자가 정리.
- **onPlaceTried (시도 결과 콜백)**: *onPlaced (이미 놨다)* → 시도 결과 명명 자가 전환.
- **ExternalRule**: 외부 라이브러리 (`omok-library`) 호출. ForbiddenThree/ExceedFive 등 어댑팅.
- **fourORjangX / findDiagonal1·2**: 1단계 명명 부적합 — 2단계에서 *44/장목/대각선 Down·Up* 명시.
