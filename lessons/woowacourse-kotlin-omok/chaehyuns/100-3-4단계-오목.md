### 1. 자율 ≠ 자족 — *의도된 방향 외부 변경 OK*

제리의 *"스스로의 힘으로만 일을 처리 할 수 있는 객체는 많지 않기 때문에 의도한 방향대로 동작할 수 있도록 API 를 설계하면 됩니다"* 어휘가 *자율 객체 정의의 *상보적 어휘***.

- **자율 강박 (잘못된 직관)**: *외부 호출 = 자율 깨짐* → *모든 동작 내부에서 결정*
