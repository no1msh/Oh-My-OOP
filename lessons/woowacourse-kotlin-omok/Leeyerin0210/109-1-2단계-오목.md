### 1. *외부 라이브러리 차용 → invariant ±1 누설* (1차 PR 의 깊은 부채)

시아의 1차 PR (병합 X) 의 명시:

> *"선배 기수의 렌주룰 알고리즘을 가져와서 적용하는 동안 코드가 많이 더러워 진 것 같습니다. 좀 더 효율적으로 가져온 코드를 적용하는 방법이 있을까요?"*

```kotlin
// Col 의 범위를 1씩 늘려서 가져온 알고리즘에 맞춤
// 본래 0..14 인 보드 좌표가 외부 알고리즘의 -1..15 사용 패턴에 맞춰 늘어남
class Col private constructor(...) {
    companion object {
        // 범위 ±1 늘어남 = invariant 손상
    }
}
```

→ **인사이트** (Position invariant 가 *알고리즘 차용으로 손상*): *외부 알고리즘이 보드 외부 좌표 (마이너스, 16 등) 를 일시적으로 사용* → *Position 의 invariant 가 그 범위로 늘어남* → *모든 Position 호출자가 invariant 가 더 약한 객체를 받음*. *알고리즘 호환을 위해 도메인 모델 invariant 가 손상되는 안티패턴* — `borrowed-vocabulary-without-meaning` 의 *invariant 측 변주*.

해결책 (시아 자가 도달): *알고리즘이 -1..15 범위가 필요하면 알고리즘 내부의 임시 자료형* 으로 두고 *Position 은 도메인 invariant (0..14) 만 책임*. **코비/8 + 하티/49 *Coordinate vs Point invariant 경계* 어휘의 변주**.

## 얻은 교훈 (OOP / 설계)

1. **외부 코드 차용 = invariant 종속성**. 외부 알고리즘이 사용하는 임시 범위 (-1..15) 가 내 도메인 모델 (Position 0..14) 의 invariant 를 흡수. *시간 절약 (차용 그대로)* vs *도메인 invariant 보존 (전면 재작성)* 의 trade-off. 시아의 *2차 PR 자가 회수* = 메타 M2 학생 측 7번째 학습 경로. m6z1/113 + 타마/137 와 같은 결.

2. **책임 분리 → Tell-Don't-Ask 위반 변주**. *책임을 Stone → Position 으로 옮기면* → *호출자가 `stone.position == ...` 비교 외부화* → *책임 분리가 더 큰 캡슐화 위반을 만듦*. 시아의 *자가 질문이 본질*. *분리 방향이 어디로 메시지를 보내는지* 가 핵심 — 그저 분리 X.

3. **private constructor + 팩토리 = invariant 단일 자리 보장**. 외부에서 `Col(잘못된값)` 직접 생성 차단 + `Col.from(int)` 한 자리에서 invariant 검증. 시즌 1 ippnsj/1 *Referee* 시드 결의 시즌 2 변주.

4. **`!!` 회피 = 도메인 시나리오 자가 인지**. *"마지막 돌이 없을 수도 있다"* = 게임 시작 직후의 도메인 사실. `!!` 사용 정당화는 *도메인 시나리오가 모두 non-null 보장* 일 때만. 4 reviewer 다른 시선 (둘리/벅벅/제리/두루) → 4번째 시선 = *실수 가능성*.


6. **`signature-name-mismatch` 의 역방향 = 시그니처에 정보가 있으면 파라미터 이름 생략**. `from(int: Int)` 의 `int` = 타입 이름 = 정보 부재. `from(Int)` = 타입이 의미. *시그니처가 도메인 의미를 표현하는 한 자리* — 두루의 Kotlin 컨벤션 어휘.

7. **외부 노출 = 깜빡 누설 신호**. *디버깅 자국* (rule 외부 노출) 이 외부 API 로 깜빡 누설. *getter 생성 = 캡슐화 깸의 시간적 자국* 어휘. dpcks0509/91 *불변 누수* 결의 1·2단계 시드.

8. **`borrowed-vocabulary-without-meaning` 학생 측 7번째 학습 경로**. 시아 = *차용 → invariant 손상 자가 자각 → 전면 재작성*. m6z1/113 (책 어휘 회수) + sh1mj1/96 (사전 방어) + 채채/58 (적용→토론→자가 기준) + 타마/137 (차용→자각→제거) + 환노/105 (사전 자가 거부) + 하티/49 (State 패턴 적용 → 회수) + **시아/109 (외부 알고리즘 차용 → 전면 재작성)** = **7 경로**.
