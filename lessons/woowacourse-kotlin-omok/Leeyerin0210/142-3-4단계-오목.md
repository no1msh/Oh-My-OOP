### 1. `Intent extras` *상수화 + object 묶기* — Activity 간 키 공유 어휘 정점

두루 (LoginActivity.kt):

> *"이부분은 아래와 같이, intent 로 넘기는 값들에 대해서 상수화를 볼 수 있겠다는 생각이 듭니다~"*

```kotlin
object Extras {
    const val NICKNAME = "nickname"
}

// RoomListActivity.kt
currentNickname = intent.getStringExtra(Extras.NICKNAME) ?: return

// LoginActivity.kt
startActivity(Intent(this, RoomListActivity::class.java).apply {
    putExtra(Extras.NICKNAME, nickname)
})
```

→ **인사이트** (Tell-Don't-Ask 의 Android 변주 — briandr97/50 *intentFor 팩토리* 결의 시아 변주): *Activity A → Activity B 데이터 전달*은 *Intent extras 키 문자열* — 양쪽에 *동일 문자열 박힘* = 결합 누설. `object Extras { const val NICKNAME }` 한 자리 = *키 문자열 단일 출처* (single source of truth). briandr97/50 *intentFor 팩토리 (호출자가 키 모름)* 의 *상수만 분리* 변주 — 캡슐화 정도는 더 약하지만 Android 입문 단계의 *현실적 절충*. **라코식 *학습 단계 우선순위* 의 Activity 측 변주**.

## 얻은 교훈 (OOP / 설계)

1. **Intent extras = 키 문자열 단일 출처 어휘**. `object Extras { const val NICKNAME }` — Activity 간 결합의 *키 문자열을 한 자리에*. briandr97/50 *intentFor 팩토리* 의 *상수만 분리* 변주. 캡슐화 정도는 약하지만 *시즌 입문 단계의 절충*.

2. **strings.xml = 도메인 vs 표현 분리의 Android 정형**. *사용자 보이는 문자열 = 표현 레이어* / *코드 = 도메인 레이어 + R.string.xxx 참조*. 토리/51 *Contract 어휘* 의 *strings.xml 변주*. `responsibility-by-layer` 의 *플랫폼 리소스 측 변주*.

3. **onCreate 다이어트 = 라코식 문장 단위 설계의 Android 변주**. onCreate = *Android 진입점 자석 자리* → *역할별 함수 분해* (setUpView / setUpListeners / loadFromDb). 호두/103 결.

4. **lateinit vs by lazy = 2년 학생 자가 학습 4번째 시드**. ippnsj/33 (2023) + 포르/125 + 타마/137 + **시아/142**. *지연 초기화의 책임 자리 (var + null-safe vs val + lazy)* 자가 학습.

5. **학습 단계 우선순위 두루 변주**. *학습 단계 외 토픽 (로그 레벨 / DB Migration / enableEdgeToEdge)* = *명시 + 강제 X + URL 동반 + 자가 기준 형성 권장*. 라코식 *코루틴 절제* 결의 두루 어휘.

6. **`borrowed-vocabulary-without-meaning` 의 시각적 어색함 변주**. 시아 *Log.wtf 만 가득 → 다른 표기로 변경* = *시각적 어색함 자가 자각 = 어휘 답습 회수*. 파이로 *"의미 모르지만 이전부터 써왔으니"* 의 학생 측 자가 회수.

7. **`change-scenario-based-abstraction` 의 *공유 가능성* 측 변주**. Query 상수화의 동기 = *현재 한 Activity 만 사용해도 추후 다른 Activity 가 공유 가능*. 두루의 *공유 시나리오* 어휘.

8. **`borrowed-vocabulary-without-meaning` 의 Android 자동 생성 변주**. enableEdgeToEdge = Android Studio 자동 추가 → *의도 자가 파악 X 유지* → *경로 자가 추적 후 의미 학습*. 자동 생성 어휘도 *의미 자가 학습 요구*.

## 도메인 특수 어휘 (Android + SQLite)

- **`LoginActivity` / `RoomListActivity` / `MainActivity`**: 3 화면 분리 — Login → 방 목록 → 게임
- **`Intent extras` / `getStringExtra(key)`**: Activity 간 데이터 전달 — 키 문자열 단일 출처 `object Extras`
- **`startActivity(Intent(...).apply { putExtra(...) })`**: 화면 전환 어휘
- **`strings.xml`**: 사용자 문자열 리소스 — 도메인 vs 표현 분리 자리
- **`DbHelper` `onUpgrade`**: SQLite 버전 변경 시 데이터 마이그레이션 — *DROP + CREATE = 데이터 손실 vs ALTER = 데이터 보존*
- **`SqlLite Migration`** (공식 가이드 URL): `developer.android.com/training/data-storage/sqlite`
- **`lateinit var`**: 비-null 보장 + 지연 초기화 (var, 변경 가능)
- **`by lazy { ... }`**: val + 첫 호출 시 초기화 (불변)
- **`enableEdgeToEdge()`**: 화면 가장자리 확장 — Android Studio 기본 세팅 자동 추가
- **`onCreate(savedInstanceState)`**: Activity 진입점 — 화면 그리기 / 리스너 부착 / DB 복원 모이는 자석 자리
- **`Log.d / Log.e / Log.i / Log.wtf`**: 로그 레벨 — 디버그 / 에러 / 정보 / What a Terrible Failure
- **`R.string.xxx`**: 코드가 문자열 자체 모르고 키만 참조
- **EOF 줄바꿈**: `Ensure every saved file ends with a line break` — POSIX 호환 + git diff 안정성
- **`./gradlew clean ktlintCheck`**: Kotlin 스타일 검증 (PR #109 두루 권장의 #142 연속)
- **`cmd + shift + L`**: IntelliJ 코드 정렬 단축키
- **`enableEdgeToEdge`** 자동 추가 → *외부 어휘 답습의 Android 자동 생성 변주*
