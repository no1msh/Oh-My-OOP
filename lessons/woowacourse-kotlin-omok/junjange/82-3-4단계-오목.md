### 6. as → sealed when — Kotlin 어휘 정확성

`as` (강제 캐스팅) → `as?` (null 안전) → `when` + sealed (분기 강제) 어휘 진화:
- `as`: *런타임 가정 기반 + 실패 시 ClassCastException*
- `as?`: *실패 시 null 반환 + 호출자 null 분기*
- `when` + sealed: *컴파일 타임 모든 분기 검증*

에디의 *짧은 자가 자각 + 즉시 반영* (*"타입 캐스팅 에러가 발생할 것 같습니다!.. 개선했습니다!!"*) 어휘 = *어휘 정확성 학생 자가 학습*.

블랙잭 INSIGHTS 메타 M2 (*그저 좋다 함정 회피*) + INSIGHTS 3 (State sealed) 동시 적용 — Kotlin 어휘를 *그저 짧게 줄이는 도구*로 쓰지 않고 *안전성 + 명시성* 측면으로 선택.

## 도메인 특수 어휘 (3·4단계 — Android + SQLite)

- **오목 모듈 분리** (`app/build.gradle.kts:48`): 도메인 + Android app 모듈 분리. *외부 라이브러리화 시나리오 (제이든 PR #63 어휘) 의 학생 자가 적용*.
- **`OmokGameActivity` 추상 클래스**: Activity 추상화. 자식 Activity 가 게임 화면별 분기. *Activity 추상 클래스 + 모듈 분리* = Controller 정체성 *에디식 분기 후보*.
- **`UiState` sealed**: `Loading / Loaded(data) / Empty / Error` 4 상태. 화면의 *완전한 분기 설계* + 컴파일 타임 분기 누락 검출.
- **`runCatching { ... }`**: Kotlin 표준 라이브러리. 블록 안 throw 를 `Result.failure` 로 변환. 호출자가 *성공/실패 분기 처리*.
- **`Result<T>`**: 성공/실패를 값으로 표현. `getOrNull` / `onSuccess` / `onFailure` 어휘.
- **`sealed Exception`**: Exception 계층을 sealed 로 정의. *예외 종류 명시 + when 절 분기 강제*.
- **`OmokRepositoryImpl`**: Repository 패턴 구현. 데이터 출처 추상화 (DB / 네트워크 / 캐시).
- **`Contract` 분리**: DB 테이블/컬럼 명을 상수 객체로 정의. 토리 결의 *시즌 초기 시드*.
- **Entity (`local/Omok.kt`)**: SQLite 행 표현. 도메인 모델과 다른 어휘 (mapper 로 변환).
- **mapper**: Entity ↔ Domain ↔ UiModel 변환. *경계 한 자리 변환* 어휘.
- **`OmokDbHelper`**: SQLiteOpenHelper 상속. *유효하지 않은 컬럼명 조회 = 앱 비정상 종료* (제이든 어휘).
- **`as Type Casting`**: 강제 캐스팅. *UiState.Success.Empty 가 들어오면 ClassCastException*. sealed when 으로 안전.
- **`let / Elvis / run` 조합**: Kotlin 스코프 함수. *run 마지막 실행문 반환* 으로 예상치 못한 결과. Listener 활용 권장.
- **`androidTest/` 디렉토리**: Instrumented test (Android Context 필요). `@RunWith(AndroidJUnit4::class)` + `ApplicationProvider.getApplicationContext()`.
- **`Test Fixture`**: 동일한 초기화 코드 중복 시 추출. galcyurio/토리 (`testing.googleblog.com`) 결의 *제이든 변주*.
- **`gitignore`** (Android.gitignore): 빌드 산출물 + 로컬 설정 제외. *공식 GitHub gitignore 자료 URL*.
- **OMokGame 책임 위임**: Activity → OMokGame *상태 꺼내와 비교 → 객체가 스스로 판단 + 리스너로 알림*. Tell-Don't-Ask 안드로이드 정점.
- **Listener (View 의존성 분리)**: `oMokGame.onTurnFinished = { ... }` 같은 콜백 패턴. *고차함수 vs interface 협력*의 안드로이드 변주.
