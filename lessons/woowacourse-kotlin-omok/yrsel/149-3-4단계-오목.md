### 2. DAO 정의 자가 정정 — 어휘 답습 vs 의미 자가 학습

제이든 (`StoneDao.kt`):

> *"DAO의 정의가 무엇이라고 생각하시나요?*
> *DAO는 현재 SQLiteDatabase를 사용함에 있어 `DB에 접근하고 쿼리를 실행하는 클래스` 입니다.*
> *현재 Stone은 DAO보다 오히려 Entity에 가깝지 않을까요?*
> *다만, SQLiteDatabase를 사용하는 현재 시점에서 Entity도 필요한지는 고민해보셔야 할 사항입니다."*

채넛 자가 정정:

> *"`DAO(Data Access Object)`에 대해 오해가 있었습니다.*
> *`DAO`는 도메인을 손상시키지 않기 위해 데이터를 접근할 때 사용하는 용도로 이해하고 `도메인 <-> 데이터베이스에서 사용되는 형식` 으로 변환해주는 역할이라고 생각했습니다.*
> *현재 `DAO`에 대해 설명해주신 정의를 읽고 다시 코드를 보니 `DAO`의 역할이 아닌 `Entity` 같다는 것에 동의합니다 !*
> *`DAO`에게 `DB`에 접근하고 쿼리를 실행하는 클래스의 역할을 부여했는데 적절하게 적용되었을까요 ? (cf272af)"*

→ **인사이트** (`borrowed-vocabulary-without-meaning` 17번째 MCP 룰 후보 보강): 학생이 *DAO* 어휘를 *도메인 ↔ DB 변환자* 의미로 *답습*하고 있었다 (= Mapper 역할). 제이든이 *DAO 정확 정의 = DB 접근 + 쿼리 실행* 으로 정정. 파이로 *"제일 최악 = 의미 모르지만 이전부터 써왔으니"* 어휘 결의 *학생 측 자가 정정 사례* 정점. *어휘 자체의 정의 → 코드 책임 매핑*. 다이스/129 *어휘 자체를 학습 대상* 결의 *학생 자가 정정 변주*.

### 5. `Cursor` use 확장 함수 도입 — `AutoCloseable` 학생 자가 학습

제이든:

> *"`This Cursor should be freed up after use with #close()` 이러한 경고 문구가 나타나지 않나요? 어떤 내용이며 어떻게 개선해야 할까요?"*

채넛:

> *"IDE에서는 `@SuppressLint("Recycle")` 과 같은 어노테이션을 추가해주려고 했습니다. ...*
> *`Cursor` 객체를 사용한 후에는 자원을 정리해달라는 의미입니다.*
> *코틀린에서의 `use` 확장함수를 활용해서 `AutoCloseable` 객체를 사용 후 정리할 수 있게 하였습니다.*
> *```kotlin*
> *fun fetchAllStones(): List<Stone> {*
> *    readableDatabase.rawQuery(OmokContract.SQL_FETCH_STONES, arrayOf()).use { cursor -> ... }*
> *}*
> *```"*

→ **인사이트** (`responsibility-by-layer` 변주): 안드로이드의 *Cursor* = *자원 보유 객체*. *명시적 close() 호출* + *try-finally* = 자바 식 보일러 / *use 확장함수* + *AutoCloseable* = Kotlin 식 *자원 안전 자동 해제*. **gahyunkim/136 의 *use 확장 함수 자가 narrate 정점* 와 같은 결의 다른 학생 도달**. *@SuppressLint 어노테이션 회피* = *경고 무시 vs 정확 해결* 의 *학생 자가 선택*.

## 도메인 특수 어휘 (3·4단계 — Android + SQLite)

- **DbHelper / SQLiteOpenHelper**: 안드로이드 SQLite 헬퍼 베이스 클래스.
- **StoneDao**: 자가 정정 — 처음에 *Mapper 의미로 답습* → *DB 접근 + 쿼리 클래스* 정확 정의 도달.
- **OmokRepository / StoneLocalDataSource / StoneFakeDataSource**: Repository/DataSource 분리 시도 → *학습 단계 외* 자가 회수.
- **fetchAllStones / fetch**: 함수명 vs 동작 불일치 + 책임 위치 잘못 정점 사례.
- **Cursor + use 확장 함수 + AutoCloseable**: 자원 해제 학생 자가 도달.
