## 도메인 특수 어휘 (1·2단계 빅스 한정)

- **Observable (interface)** + Observer 패턴 학생 자가 도전: 콘솔 미션에서 *뷰가 모델 인터페이스 직접 의존*. 블랙잭 #59 결.
- **Board + backing property (`_board`)**: 생성자 언더바 회피 → 내부 가변 / 외부 노출 분리.
- **CoordinateState (EMPTY/BLACK/WHITE)**: m6z1/113 의 PointState/StoneColor + 공백/104 의 StoneColor/PointState 와 같은 결의 *3 단계 enum* 어휘.
- **ForbiddenThree.findDiagonal1/2 → Down/Up**: 숫자 접미사 → 도메인 어휘.
- **ExceedFive.fourORjangX (44 + 장목)**: OR 명명 → 직관적 명명 (구체 명명 변경은 미작성).
- **Stones (다른 클래스 포함 파일)**: 한 파일 한 클래스 컨벤션 위반.
- **Constant.kt + const val**: 컴파일타임 상수 학습 (val → const val).
- **object OutputView + 상수 위치**: 클래스 직접 멤버 컨벤션 (companion 회피).
- **객체지향 생활 체조**: 한 단계 들여쓰기 / 줄여쓰지 않기 / 한 파일 한 클래스 — 1·2 단계 일반 학습.
- **MVC 두 변종**: 전통적 MVC + Observer (push 모델) vs 변형된 MVC (Controller 매개) — 학생 자가 비교 narrate.
