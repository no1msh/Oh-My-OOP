reviewer 짧은 확정:

→ **인사이트** (블랙잭 INSIGHTS 1 — Tell-Don't-Ask 의 *Android Activity 측 변주*): *startActivity + putExtra(KEY, value)* = *호출자 (HomeActivity) 가 *대상 Activity 의 키 값* 알고 있음*. *대상 Activity 의 동반 객체* 에 *intentFor(value) 팩토리* 만들면 *호출자는 키를 모름* — *대상이 자기 인텐트 생성을 캡슐화*.

```kotlin
// 변경 전 — 호출자가 키 값 알고 있음
val intent = Intent(this, RoomMakingActivity::class.java)
    .putExtra(RoomMakingActivity.KEY_NAME, name)
startActivity(intent)

// 변경 후 — 대상 Activity 가 인텐트 생성 캡슐화
startActivity(RoomMakingActivity.newIntent(this, name))
```


블랙잭 INSIGHTS 1 (Tell-Don't-Ask) + INSIGHTS 7 (도메인 vs 표현 — *키 = 표현 디테일*) 결합. m6z1/139 의 *흑/백 → Stone → Resource 중간 다리* 와 *같은 결의 Activity 측 변주*.

→ **MCP 룰 후보 / 트레이드오프 어휘** — *호출자가 어떤 지식을 모르도록 캡슐화* = 일반화 후보. 다만 *Android 특화 어휘* (intentFor 팩토리) 라 *플랫폼 어휘 회피 룰 작성 시 도메인 어휘로 일반화 필요*.
