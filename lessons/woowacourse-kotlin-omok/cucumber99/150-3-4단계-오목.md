### 5. 시즌 종료 머지 결언 — *Application 상태 vs DAO + Activity 역할 관점*

디노 PR body 머지 결언:

> *"- Application에서 상태를 가지고 있는 것은 좋지 않는게 맞습니다. 하지만 DAO는 상태라고 보기 어렵다고 생각합니다 ㅎㅎ*
> *- Activity의 역할은 여러가지 관점에서 볼 수 있습니다. 모든 것을 다 할 수도 있고, View에 관한거만 볼 수도 있고, 때로는 Activity의 Lifecycle만 처리하게 만들 수도 있습니다. 어떤 관점에서 어떻게 설계하냐에 따라 다른데 이것은 차차 알아가보는 것을 추천드립니다"*

> *"오이 레벨1 마지막 미션까지 고생많으셨습니다. 방학때 잘 쉬시고 레벨2때도 화이팅해봐요!"*


**Application 상태 vs DAO 분류**:
- *Application 안 상태 (예: 현재 사용자, 게임 진행 상태)* = *전역 가변 상태* → *피하기*
- *DAO* = *DB 접근 객체* (상태 X, 행위 응집) → *Application 보유 OK*

오이가 *"Application에서 상태를 가지고 있는 것"* 에 대해 *PR body* 에 자가 의문 (코드 외 textual) → 디노 *분류 정정* (DAO 는 상태 X).

**Activity 역할 관점 4 분기**:
1. 모든 것 다 하기
2. View 만 보기
3. Lifecycle 만 처리
4. *어떤 관점에서 설계하냐 다름* — *차차 알아가기*

→ **Controller 정체성 4 분기 (HANDOVER §15)** *라코식 / 토리식 / 벅벅식 / 말리빈식* 의 **디노식 = 관점 다중성 명시** 변주. 디노 = *직접 정답 + 짧은 칭찬* (HANDOVER §1) + *Activity 역할 관점 다중성 명시* = **시즌 종료 시점 Controller 정체성 5 분기 확장**.

블랙잭 INSIGHTS 메타 M2 *그저 좋다 함정* 의 *관점 의존 어휘* — *어떤 관점인지가 답 결정*.

## 얻은 교훈 (OOP / 설계)

1. **OmokApplication + DAO + String resource 동시 채용 = Android 표준 어휘 정착**. 오이가 *시즌 종료 시점에 학습 단계 우선순위를 미리 도달* — 포르/152 *DAO 모름 인정 + 학습 약속* 과 *같은 시기 학생 측 두 길*. 라코 *학습 단계 우선순위* 어휘의 *학생 자가 도달 측면* — **시즌 종료 시점 두 학생 두 길의 시간성 정점**.

2. **lateinit var → by lazy = 변경 시나리오 기반 추상화 (Android 어휘)**. 디노의 *"순서가 바뀌거나 setupBoard 전에 사용해야하는 코드가 추가 되었을 때"* 어휘. MCP 룰 `change-scenario-based-abstraction` 의 *Android lateinit 측 변주 + 디노 reviewer 측 변주* 추가. ippnsj (2023) → 포르 + 오이 (2025) **2년 어휘 일관성 4번째 학생 정착**.

3. **ImageView 미리 array 보유 = 호출 빈도 × 비용 영향 격리**. *findViewById 매번 호출 비용* → *초기화 시점 1회 + array 직접 접근*. 라코의 *"룰이 매번 생성되지 않도록"* (Hevton/88) 어휘의 *Android ImageView 측 변주 + 디노 reviewer 측 변주*. MCP 룰 `change-frequency-reduction-design` 의 *호출 빈도 어휘 강화*.

4. **Game.kt return 무의미 = 시그니처-이름 일치 9 사례 누적**. *호출자가 보지 않는 return = 시그니처 노출 산재*. MCP 룰 `signature-name-mismatch` 의 *시즌 종료 시점 정착 누적 사례*. m6z1/139 + Hogu59/97 + 호두/68 + murjune/72 + murjune/92 + dpcks0509/91 + krrong/36 + 악어/97 + **오이/150** = 9 사례.

5. **Application 상태 vs DAO 분류 = 그저 좋다 함정의 분류 변주**. 디노의 *"DAO는 상태라고 보기 어렵다"* 어휘 — *Application 안 두는 것 = 무조건 나쁨 X* + *분류 (상태 vs 행위)* 기반 결정. 블랙잭 INSIGHTS 메타 M2 *그저 좋다 함정 회피* 의 *Android Application 측 변주*.


7. **시즌 종료 머지 결언 정착 — 둘리 + 디노 동일 시점**. *"방학 + 레벨2 화이팅"* 어휘가 *두 reviewer 동일 시기* 시즌 마무리 — **코퍼스의 시즌 단위 시간성 봉인**. 학습이 *시즌 단위 다음 미션으로 연결* 의 *시즌 종료 정착 정점*.
