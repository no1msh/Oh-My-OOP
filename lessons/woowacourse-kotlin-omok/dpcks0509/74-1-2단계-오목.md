### 2. Board 자료구조 자가 선택 — MutableList → Array

라코 (Board.kt):

> *"이중 배열의 구조가 x, y 좌표에 접근하는 개념에 적합한 자료구조일까요?"*

채드:

> *"이중배열을 MutableList보다는 Array로 처리하는게 더 적합하다고 생각하여 수정하였습니다!"*

→ **인사이트** (Kotlin 어휘 깊이 + 자료구조 ↔ 도메인 적합도): *이중 배열* 의 *x, y 좌표 접근* 어휘는 *고정 크기 + O(1) 접근* 이 적합. *MutableList<MutableList<T>>* = *동적 크기 (오버스펙)* + *O(1) 접근* (사실상 ArrayList 도 O(1)). *Array<Array<T>>* = *고정 크기 (정확한 어휘)* + *O(1) 접근*.

채드의 *자가 선택* 어휘 — 라코는 *질문만*, 채드는 *자료구조 결정*. 다만 라코 후속 어휘 (*"지금 프로그램에서는 보드의 크기가 15라는 것을 너무 쉽게 생각하는 것처럼 보입니다."*) 가 *Array 선택의 위험*을 짚음 — *고정 크기*가 *15 하드코딩과 결합*. 채드의 자가 선택은 *부분 맞음* — *자료구조*는 정확하지만 *크기 매개변수 (15)* 의 *위치*는 별도 토론.

### 4. Backing property → private set 채택

라코 (Board.kt #1536373740):

> *"private var을 사용한 이점이 있을까요?"*

채드:

> *"_turn을 삭제하고 turn을 var로 선언한 후 private set을 이용하는 방식으로 수정하였습니다!"*

→ **인사이트** (호두 Junyoung-WON/68 의 *Backing property vs private set* 어휘와 *같은 결*): *Backing property* = *외부/내부 표현 분리* 패턴 (예: 내부 MutableList → 외부 List 노출). *private var* + *public val* 분리만 한다면 *과한 패턴*. *var x: T private set* 이 *Kotlin 표준 어휘* — 외부 차단 + Kotlin 가벼움.

채드의 *Backing property → private set* 전환이 두 학생 (호두 + 채드) 의 *공통 학습*. 블랙잭 INSIGHTS 메타 M2 (*그저 좋다 함정*) 의 *Kotlin 어휘 측 변주* — *Backing property 라는 패턴 이름의 익숙함* 이 *언제 그 패턴이 필요한가* 를 지움.

→ **인사이트** (블랙잭 INSIGHTS 8 — 일급 컬렉션 캡슐화 *외부 가변 누수 차단*): *내부 MutableList* 가 *외부에 그대로 노출* → *외부에서 가변 메서드 (add, remove, set) 호출 가능* → *Board 의 invariant 무력화* (예: 같은 위치에 두 돌 놓이지 않게 보장).

- 또는 *Array<Array<...>>* 의 *불변 reference* (요소만 가변)

채드의 *모범 답안 적용* — 외부 노출 차단. chanho0908/110 의 *외부 가변 누수 학생 자가 검증* 어휘와 *같은 결*.

### 1. Wirfs-Brock 식 두 안 비교 — 책임 분배의 도구

라코의 *Board vs Turn 두 안 비교* (#1 못한 점) + *턴이 이전 돌 보유 vs 다른 누군가가 이전 턴 보유* + *라이브러리 테스트 vs 어댑터 테스트* — 한 PR 안에서 *세 가지 Wirfs-Brock 식 질문* 반복.

### 2. 데이터 위치 = 사용처 추정 — 라코의 *"단순히 UI에서 ... 위함은 아닐까"* 어휘

라코의 *"단순히 UI에서 마지막에 놓은 돌을 출력하기 위해 결정하지는 않았을까요?"* 어휘가 *데이터 위치 결정 도구*:

- *데이터가 X 객체에 있는데, 그 데이터의 진짜 사용처가 어디?*
- *사용처가 X 의 본질 (현재 차례)* 와 *다른 부분 (UI 출력)* 이면 *그 데이터는 X 에 있을 이유 부족*
- *데이터를 사용처에 가깝게 이동* 또는 *그 데이터를 보유할 적절한 객체* 새로 도출

### 4. 단일 출처 (Single Source of Truth) — 상수의 부분 진전

채드의 *Board.BOARD_SIZE 단일 출처 + Point.MAX_POINT = Board.BOARD_SIZE 참조* 가 *부분 진전*. *완전한 해결*은 *외부 주입* (Board(size: Int)) — *상수 단일 출처*가 *Board 가정* 유지.

학습 단계:
