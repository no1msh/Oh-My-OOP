### 1. `by lazy` vs `lateinit`

말리빈 (MainActivity.kt):

> *"`by lazy() { }` 를 활용해도 괜찮아보이네요 :) 둘의 차이점은 무엇일지 공부해보셔도 좋겠어요 🙂"*

써니 응답:

> *"불변으로 사용되는 프로퍼티를 가변으로 lateinit 함으로써 신경 쓰였는데 lazy를 사용해 초기화 하면 되는 거였군요! :) 감사합니다 :)"*

→ `lateinit var`는 가변 프로퍼티를 나중에 초기화하고, `by lazy { ... }`는 최초 접근 시 초기화한 뒤 값을 유지한다. 불변 값으로 사용할 프로퍼티에는 `by lazy`를 선택할 수 있다.

## 도메인 특수 어휘 (3·4단계 오목 + Android + SQLite — 써니)

- **MainActivity**: Android 진입점. View 관련 책임과 기능은 별도 객체로 분리할 수 있다.
- **BoardView**: 오목판 View 객체.
- **OmokDBHelper (SQLiteOpenHelper)**: SQLite 헬퍼. 데이터 접근과 도메인 조작의 책임을 나눌 수 있다.
- **insertData / deleteAll / selectAll**: 실제 처리 대상과 동작을 구체적으로 드러낼 수 있는 메서드명.
- **eventListener**: 구체적인 이벤트를 나타내도록 이름을 정할 수 있는 Listener.
- **runningGame**: 게임 상태 자체를 반환하도록 변경을 고려한 메서드.
- **determineImageView**: 중복 호출을 정리할 대상 메서드.
- **let / by lazy / lateinit**: Kotlin 스코프 함수 및 프로퍼티 초기화 방식.
- **Kotlin-Docs (kotlinlang.org)**: Kotlin 공식 문서의 스코프 함수 설명.
