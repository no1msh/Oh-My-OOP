### 1. getDatabase() = 3 책임 — 함수 분리 시그니처 ↔ 이름 불일치

```kotlin
// 리팩토링 전 — getDatabase() 3 책임
fun getDatabase(): SQLiteDatabase {
    // 1. DB 생성
    val db = ...
    // 2. 모델 초기화
    omok = OmokGame(...)
    // 3. DB 로부터 데이터 불러오기

    return db
}
```

제리:

> *"해당 함수는*
> *1. DB 생성*
> *2. 모델 초기화*
> *3. DB 로 부터 데이터 불러오기*
> *3개의 역할을 수행하고 있는데요, 함수의 분리가 필요하지 않을까요? getDatabase() 라는 네이밍으로 수행하는 일을 모두 표현하기 어려운 것 같아요."*

→ **인사이트** (블랙잭 INSIGHTS 6 — 한 데이터 두 책임 + MCP 룰 후보 `signature-name-mismatch`): *함수 이름 (getDatabase) = DB 반환 한 일* + *시그니처 (반환 SQLiteDatabase) = DB 반환 한 일*. 그러나 *함수 본체 = 3 책임*. **이름 + 시그니처 둘 다 일치 + 본체만 위반** = *이름·시그니처가 함수 책임을 *배신**.
