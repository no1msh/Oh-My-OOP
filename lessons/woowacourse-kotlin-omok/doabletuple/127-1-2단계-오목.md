## 도메인 특수 어휘 (1·2단계 디랙 시즌 2 후기)

- **Position (typealias Point) — invariant 단순**: x,y 만 + 보드 범위 모름. 보드 관심사 = Board 가 보유.
- **Points → Set<Stone>**: 중복 불가 + O(1) 조회. List 순회 O(n) 회피.
- **Player 클래스 폐기**: 책임 분배 후 빌껍데기 자각 → 삭제 (Black/White = Turn enum 으로 흡수).
- **Game (도메인 코어 + Rule 보유)**: 외부 라이브러리 의존 한 자리. 다른 모든 모델은 라이브러리 모름.
- **Rule 인터페이스 + RenjuRule (라이브러리 의존)**: 변경 빈도 다른 두 책임 분리 (턴 진행 ≠ 룰 적용).
- **마지막 돌: Stone?**: nullable 채택. 부재 명시 = 도메인 의미. 무의미 초기값 (흰돌 1,1) 회피.
- **sealed class MoveResult { Success / Failure(reason) }**: Exception + 문자열 비교 회피. exhaustive when + 케이스별 데이터.
- **방어적 복사 → toList()**: 깊은 복사 불필요. 읽기 전용 보기로 충분.
- **외부 라이브러리 (budool-omok-rule)**: Game 한 자리만 알게. 도메인 모델 = 순수.
- **BOARD_SIZE 15**: Position invariant 가 결정 (1~15 → Board 사이즈). 매직넘버 산재 회피.
- **RenjuRule width/height**: 라이브러리 사이즈 일관성. Game 이 단일 출처.
- **테스트 위한 public = 추출 신호**: 책임 분리 후 자연스러운 public 인터페이스.
