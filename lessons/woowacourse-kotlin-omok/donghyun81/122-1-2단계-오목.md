## 얻은 교훈 (OOP / 설계)

### 1. Finish 의 placeStone 강제 = LSP 위반의 약한 형태

부모 추상이 *모든 자식에게 placeStone 구현 강제* — 자식 중 *실제 동작 자체가 의미 없는 자식 (Finish)* 가 있으면 *no-op 구현*이 LSP 신호. *옵션 3 (호출자 가드)* 또는 *상태 머신 종결을 별도 표현* 이 더 깔끔.

오목 코퍼스 *상태 패턴 LSP 위반 학생 자가 도달*: haeum808/56 + 동전/122 — *2 학생 누적*.

### 2. View 의 반환 = 1차원 (raw) vs 2차원 (UiModel 분리) 의 두 안 비교

동전의 자가 narrate가 *Factory 책임 폭증 회피 시나리오*를 미리 그려서 *View 가 파싱 + Controller 가 도메인 생성* 으로 정리. **자가 변환점** = *비즈니스 모델 = 위험 API 내포* → *UiModel 한 겹*이 *그 위험 차단*.

vagabond95 *InputView/OutputView 비대칭 룰 (입력=원시 / 출력=UiModel)* 의 *오목 측 학생 자가 도달*. MCP 룰 `presentation-layer-uimodel-asymmetry` 후보 evidence.

### 3. Size 객체 추출 = 매직넘버 → 일급 어휘

*Board size = 15* 가 *각 객체 (Row, Column, OutputView) 에 흩어진 매직넘버*. *Size(15, 15)* 한 객체로 추출하면 *변경의 단일 진원지*. *100x100 변경 시나리오* = *Size 의 한 줄 변경*.

블랙잭 INSIGHTS 5 (값 객체 invariant) 의 *오목 측 변주* — *Size 가 만들어졌다 = 검증 완료* invariant.

### 4. 어댑터 의의 = 도메인이 라이브러리를 모름 (DIP)

*도메인 = 고수준 / 어댑터 = 저수준* 의 위계. *도메인이 어댑터 인스턴스 주입*은 *고수준이 저수준 모름* 의의 위반. *Controller (저수준)* 가 어댑터 생성 + 도메인에 *Rule (고수준 인터페이스)* 만 주입.

m6z1/139 라코 *Board ↔ RuleAdapter 직접 의존* 토론의 *오목 측 다른 학생 도달*.

### 5. canPlace ↔ placeStone 사전조건 짝 약속

*질의 함수 = 모든 사전조건 노출 / 명령 함수 = 사전조건 확인 후 실행*. 짝이 어긋나면 *호출자가 안전 호출 불가능* — *질의 함수의 성공 = 명령 함수 호출 안전* 약속이 깨짐. 그러면 *질의 함수 의의 자체* 가 사라짐.

CQS 의 *짝 약속 변주*. m6z1/139 `checkPutState` 결의 *오목 측 다른 학생 도달*. MCP 룰 `command-query-separation-naming` evidence 보강.

### 6. 상태 객체에 메시지를 박으면 상태가 무력화

*상태 객체 = 호출자가 상태별 응답 결정* 의의. *도메인이 상태 + 메시지 같이 반환* 하면 *상태 객체의 분기 의의가 사라짐* (단순 String 반환과 동급). 어댑터/도메인이 *데이터 + 표현* 두 책임을 가지면, 호출자는 *둘 중 하나만 사용*하면서 *나머지가 결합 부담*.

블랙잭 INSIGHTS 7 의 *상태 객체 측 변주*. MCP 룰 후보 `state-object-emptied-by-message-leak` 후보.

### 7. SOLID 학습 = 한 원칙으로 좁히기

*5 원칙 동시 적용*은 *학습 단계 미설정*. *SRP 한 가지만* 으로 좁혀 *실제 위반/지킴 케이스*를 충분히 본 뒤 다음 원칙으로 확장. *학습 단계 우선순위* 어휘 (라코 *마른 스펀지*) 의 *코니 변주*.

chanho0908/132 의 SOLID 자가 자각 + 로버트 마틴 인용 의 *오목 측 reviewer 어휘 변주*.

### 8. Manager 폭증 = 번잡함 신호

*흐름 객체* = *하나로 응집* 권장. *Board Manager + Rule Manager + Turn Manager + ...* 분리는 *흐름의 통제 분산* → *호출자 입장에서 어디 호출인지 추적 부담*. *번잡함* 어휘가 *분리의 임계점* 신호.
