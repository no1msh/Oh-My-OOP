## 도메인 특수 어휘 (3·4단계 오목 — 멘델 + Android + SQLite)

- **Multi-module (domain / app)**: 순수 코틀린 도메인 vs 안드로이드 의존 app 분리
- **FinishedBoardState.isWin()**: 종료 상태가 다시 재검사 — invariant 위반 시나리오 (라코의 *"FinishedState(다른룰)"* 코드 예시)
- **RunningBoardState (시작/진행 미분리)**: 라코 권고 *명시 분리 + 단위 테스트* — 학생 응답 *추상 클래스로 공통 검증 위치*
- **Board (Map<Mutable>)**: 일급 컬렉션 환기 — 객체화 (`Board.putStone()`) 권고
- **Turn.next() 자기 강제**: 다음 턴 = 자신 (PR #17 일관 어휘) — 라코 권고 *N 턴 가능성*
- **sealed class TurnResult { Playing / Finished / ... }**: 라코 직접 코드 제시 — 결과 타입 진화 시즌 초기 시드
- **Application.kt while 루프 not() 누락**: 멘델 자가 디버깅 narrate
- **StoneVO.roomNum / roomId**: 미래 게임방 테이블 의도 (학생 자가 narrate)
- **StoneTableAdapter ↔ StonesHelper 책임 위배**: 명명된 책임 ↔ 실제 책임 위치 불일치
- **ToastFactory → ToastIntegratedManager → IntegratedToast**: 3 단계 명명 자가 진화 (학생 자가 학습 어휘)
- **BackKeyHandler (토스트 + 종료 부수효과 숨김)**: 외부 시선 어휘
- **MainActivity.positionClick / putStoneProcess / setStone**: 비즈니스 / UI 혼재 — 라코의 *3 단계 책임 분리* (click 전파 / put 비즈니스 / set UI)
