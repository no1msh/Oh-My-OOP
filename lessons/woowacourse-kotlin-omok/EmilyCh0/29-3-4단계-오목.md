PR #6 (1·2단계) 의 *galcyurio "GUI에서 그림으로 표현해야하는 경우"* + PR #29 의 *galcyurio "추후 새로운 enum이 추가되면"* = **두 PR 동일 reviewer 변경 시나리오 어휘 결**.
