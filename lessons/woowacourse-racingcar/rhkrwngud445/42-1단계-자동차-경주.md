## 얻은 교훈

- **이름이 외부 표현(랜덤)을 새면 결합도가 즉시 보임.** `move(randomNumber)` → `move(moveValue)` 또는 `move(number)`로 추상화.
- **`initX()` 호출 패턴 = 라이프사이클 진단.** 같은 메서드 N번 호출 시 누적되면 의도와 다른 결과. 멱등성이 깨짐.
- **전략 패턴의 lazy 계산 가치.** 도메인 객체가 사전 계산하지 않고, 실제 사용 시점에 외부 전략으로 계산. 성능 + 추상화.
- **자동차 무작위 표현 = 도메인 외부의 관심사.** 0~9 범위가 자동차의 일이 아님.
- **"뼈대 코드" 커밋의 안티패턴.** 의미 단위가 아닌 시점 단위로 커밋하면 코드 변경의 의도가 사라짐.
