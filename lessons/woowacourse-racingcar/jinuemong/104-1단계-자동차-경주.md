## 얻은 교훈

- **`lateinit`의 진짜 용도 = "non-nullable 타입 + 생성자 외부 초기화"**. 초기화 *여부*를 흐름 제어로 쓰는 건 부적절. *상태 = 변수 초기화 유무*의 매핑이 부자연스러우면 다른 도구.
- **생성자 vs body 선언 기준**: 외부에서 주는 값 → 생성자, 항상 같은 초기값으로 시작하는 invariant → body.
- **InputView에 출력문 = 책임 침범**. 입출력 분리 의미 약화. 입력 안내문도 OutputView로.
- **상수의 응집도 = 재사용성**. 한 클래스에서만 = 그 클래스 내 private. 여러 클래스 = 의미 있는 파일.
