### 4. `Deck` interface + `ShuffledDeck` 구현 + 8 덱 도메인 룰

```kotlin
interface Deck {
    fun pop(): TrumpCard
    fun makeCards(): Deque<TrumpCard>
}

class ShuffledDeck : Deck {
    private val deckPool: MutableList<Deque<TrumpCard>> = mutableListOf()
    private var currentDeckIndex = 0

    init {
        repeat(MAX_DECK_COUNT) { deckPool.add(makeCards()) }
    }

    override fun pop(): TrumpCard {
        val currentDeck = deckPool.getOrNull(currentDeckIndex)
            ?: throw IllegalArgumentException(ERROR_EMPTY_DECK_MESSAGE)
        return if (currentDeck.isNotEmpty()) {
            currentDeck.pop()
        } else {
            currentDeckIndex++
            pop()  // ← 재귀
        }
    }

    companion object {
        private const val MAX_DECK_COUNT = 8
        private val SHUFFLED_DECK: List<TrumpCard> by lazy {
            Shape.entries.flatMap { shape ->
                CardTier.entries.map { tier -> TrumpCard(tier, shape) }
            }.shuffled()
        }
    }
}
```

### 6. `getResult` 다형성 + `super` 키워드 — 4 스레드 학습

```kotlin
// Participant (공통 로직)
open fun getResult(other: Participant): GameResult {
    val myScore = cards.finalScore()
    val otherScore = other.cards.finalScore()
    return when {
        !cards.isBlackJack() && other.cards.isBlackJack() -> GameResult.LOSE
        cards.isBlackJack() && !other.cards.isBlackJack() -> GameResult.BLACKJACK
        other.cards.isBust() -> GameResult.WIN
        myScore > otherScore -> GameResult.WIN
        myScore < otherScore -> GameResult.LOSE
        else -> GameResult.DRAW
    }
}

// Player (한 가지 경우만)
override fun getResult(other: Participant): GameResult =
    when {
        cards.isBust() -> GameResult.LOSE
        else -> super.getResult(other)  // ← super 키워드
    }

// Dealer (한 가지 경우만)
override fun getResult(other: Participant): GameResult =
    when {
        cards.isBust() && !other.cards.isBust() -> GameResult.LOSE
        else -> super.getResult(other)
    }

    when {
        cards.isBust() && !other.cards.isBust() -> GameResult.LOSE
        else -> super.getResult(other)
    }
```

→ **Dealer 만 자가 처리 = *Dealer Bust + Player !Bust* 한 가지 경우** + *나머지는 super 위임*.

다만 *Player.getResult* 도 동일 패턴:
```kotlin

    when {
        cards.isBust() -> GameResult.LOSE  // ← Player Bust = 즉시 LOSE
        else -> super.getResult(other)
    }
```

→ **Player 는 자가 Bust = 즉시 LOSE** (모든 시점), **Dealer 는 자가 Bust + Player !Bust 만 LOSE**.

#### 12.1. *블랙잭 룰 정공*

- Player Bust: 무조건 Lose (자가).
- Dealer Bust: 모든 살아있는 Player Win → Dealer Lose. 다만 *Player 도 Bust = Player Lose (Dealer 의 Bust 와 무관)*.

→ *학생 코드 = 블랙잭 룰 정공*.
