### 7. 빌더 필수 속성 + `lateinit` 위험 (Thread 9)

```kotlin

    lateinit var name: String
    fun name(v: String) { name = v }

```

reviewer:

> *"Builder의 특징은 선택적으로 속성을 부여하는 것 일텐데, name을 호출하지 않고 build() 하면 어떤 문제가 생기나요? 어떻게 해결해야 할까요? **\"호출하지 않으면 이름은 빈값이다\" 라는 답변은 아니길 바랍니다..** 힌트는 이름은 필수라는 점입니다."*

학생 자가 답변:

> *"이름 없이 build() 했을 때, 해당 오류 메세지 확인했습니다!*

→ **`builder-required-property-as-constructor`** = **MCP 룰 후보** ⭐⭐ — *Builder = 선택적 속성 / 필수 속성 = 생성자*. PR #38 (`lateinit` 위험) 결 합류 누적 2 PR → ***`lateinit` 위험 어휘*** ⭐⭐⭐ 강화.

→ **`reviewer-hint-vocabulary`** — *"힌트는 X"* = 학생 사고 유도 어휘.
