### 2. `BetAmount` (value class + invariant) + `Profit` (value class + Double) + `ProfitRate` (enum + calculate) — 책임 분리

```kotlin
@JvmInline value class BetAmount(val value: Int) {
    init { require(value > MINIMUM_BET_AMOUNT) { ... } }
    fun calculateProfit(profitRate: ProfitRate): Profit = Profit(profitRate.value * value)
}

@JvmInline value class Profit(val value: Double)

enum class ProfitRate(val value: Double) {
    BLACKJACK_WIN(1.5), NORMAL_WIN(1.0), DRAW(0.0), LOSE(-1.0);

    companion object {
        fun calculateProfitRate(winLoss: WinLoss, cardStatus: CardStatus): ProfitRate = when (winLoss) {
            WinLoss.WIN -> if (cardStatus == CardStatus.BLACKJACK) BLACKJACK_WIN else NORMAL_WIN
            WinLoss.LOSE -> LOSE
            WinLoss.DRAW -> DRAW
        }
    }
}
```

→ **3 객체 분리 + 각각 책임 명확**:
- `BetAmount`: *invariant + Profit 계산*.
- `Profit`: *value class + Double*.
- `ProfitRate`: *enum + 결과/상태 조합 → rate*.
