### 3. `ManualCardFactory` 테스트 전용 + Map 받기

galcyurio: *"ManualCardFactory는 테스트를 위한 Fake 구현체이기 때문에 이를 위한 테스트 케이스는 작성되어선 안됩니다. 추가로 ManualCardFactory는 현재 테스트 케이스를 제외하고는 그 어떤 테스트 케이스에서도 쓰이지 않고 있네요. CardFactory를 의존하고 있는 BlackjackStage에 대한 테스트 케이스를 작성하다보면 필요해질 겁니다."*

galcyurio (Map suggestion):

```kotlin
// AS-IS
val cardFactory = ManualCardFactory(
    listOf(CardType.CLUB, CardType.SPADE), listOf(CardNumber.THREE, CardNumber.QUEEN)
)

// TO-BE  
val cardFactory = ManualCardFactory(mapOf(
    CardType.CLUB to CardNumber.THREE,
    ...
))
```

galcyurio 자가 *착각 사과*: *"제가 착각하고 잘못 말씀드렸네요 🙏🙇 이 구현체는 테스트를 위한 구현체니까 단순히 원하는대로 반환을 시키면 됩니다. 테스트 가독성을 위해 List로 받는 대신 Map을 받도록 처리해보면 어떨까요?"*

### 5. `when expression vs if expression`

galcyurio: *"when expression을 활용하여 `''`와 같은 불필요한 반환을 없애보세요. 변환 후에 CardType이나 CardNumber를 추가해보고 if expression과 when expression 2개 방식에 어떤 차이점이 있는지도 정리해보면 좋겠어요."*

학생: *"enum 클래스에서 when expression을 사용할 때는, else 브랜치를 사용하지 않을때 enum의 모든 항목에 대해 브랜치를 관리하도록 강제하는 차이가 있다고 정리했습니다."*

→ **MCP 기존 룰 `sealed-class-when-exhaustive`** (enum 변형) — *when exhaustive + else 강제*. PR #91·#9·#26·#43·#16·#76 결.

### 6. `테스트 static import 컨벤션`
