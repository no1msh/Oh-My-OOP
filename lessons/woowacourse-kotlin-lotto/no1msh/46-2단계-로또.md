### 2. Lotto init과 생성자 호출 순서

> 이 부분이 실제로 동작하는 경우가 있을까요? 초기화 블록과 생성자의 호출 순서에 대해 알아보세요!

→ init이 부 생성자 후 호출 → 검증이 누락된 경로 가능.

### 3. runCatching onSuccess + return

```kotlin
runCatching { payment = Payment(money) }
    .onSuccess { return payment!! }  // ⚠ !! + onSuccess 내부 return
```

## 얻은 교훈

- **init 블록 + 생성자 순서** = Kotlin 미묘. 부 생성자 → 주 생성자 → init.
- **runCatching의 onSuccess 내부 return의 함정** — `!!`을 보조하는 패턴은 위험.
