### 2. `ManualLotto` — 복수형 표현 부족

```kotlin
class ManualLotto(val lottos: List<Lotto>) { ... }  // ⚠ 컬렉션인데 단수형
```

> 해당 클래스는 로또 컬렉션을 가지고 있으므로 복수 표현형을 좀 더 드러내면 어떨까요? 외부에서 네이밍만 본다면, 단일한 ManualLotto 라고도 오해할 수 있어보여요.

→ `ManualLottos` 또는 `ManualLottoBunch`.

### 3. MutableList 반환

> MutableList 타입으로 리턴할 경우 외부에서 컬렉션의 수정이 가능할 것 같은데요. 의도된 구현이실까요?

## 얻은 교훈

- **컬렉션 = 복수형 이름** (`Lottos`, `Cars`, `Numbers`).
- **MutableList 반환 = 외부 수정 가능 위험**. List/toList()로.
