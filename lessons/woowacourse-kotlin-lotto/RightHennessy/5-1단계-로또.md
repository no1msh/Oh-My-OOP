## 리뷰어 핵심

### 1. `!!`은 null 아님 확신 시만

```kotlin
Rank.values().find { it.countOfMatch == 7 }!!  // ⚠ 7은 범위 외
```

> 만약 countOfMatch가 7이상의 값이면 어떻게 될까요? non-null assertion(!!)은 null이 아닐 것이라 확신할 때 사용하는 것이 좋습니다.

### 2. try-catch + 재귀 vs 예외 흐름

> 코틀린에서 예외를 처리하는 방법은 크게 두 종류가 있습니다.
> - 오류가 예상되는 경우
> - 오류가 예상되지 않는 경우

## 얻은 교훈

- **`!!`은 false sense of safety**. 검증 누락 시 NPE.
- **LottoNumber 값 객체로 묶으면 *풀 필요 없음***. 묶은 후 *Int로 풀어 검증*하면 wrapping 의미 약화.
