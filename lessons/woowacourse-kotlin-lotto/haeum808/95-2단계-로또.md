## 핵심 지적

### 1. Lotto가 자신 + bonus 받아 등수 반환

```kotlin
class Lotto(...) {
    fun rank(winning: Lotto, bonus: LottoNumber): Rank = ...  // ⚠ Lotto가 등수 결정
}
```

> 거의 다 왔네요! 로또가 자기 자신과 보너스 번호까지 받아서 등수를 반환하고 있네요! 등수를 계산하는 게 로또 티켓이 해야하는 일이 적절할까요?

→ 등수 결정은 *WinningLotto*의 책임. Lotto는 *자기 번호*만 알면 됨. `winningLotto.match(lotto): Rank`로 메시지 방향 반전.

## 얻은 교훈

- **메시지 방향 = 도메인 의미**. "당첨 로또가 *내 번호와 비교*" (winning.match(lotto)) vs "로또가 *당첨인지 확인*" (lotto.checkAgainst). 전자가 자연스러움.
