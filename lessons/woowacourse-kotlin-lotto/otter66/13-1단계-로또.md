### 2. `LotteryNumberGenerator`와 `LotteryGenerator` 강결합

```kotlin
class LotteryGenerator {
    fun generateLottery(): Lottery {
        return Lottery((1..6).map { lotteryNumberGenerator.generateLotteryNumber() })  // ⚠ 다른 Generator 직접 호출
    }
}
```
