## 못한 점 + 핵심 지적

### 1. Lotto에 중복 검증 누락

```kotlin
class Lotto(val numbers: List<Int>) { ... }
Lotto(listOf(1,2,1,2,1,2))  // ⚠ 중복인데 생성 가능
```

> Lotto 도메인에 대해 테스트가 이루어졌을까요? `Lotto(listOf(1,2,1,2,1,2))`와 같은 객체도 생성될 수 있겠네요. Lotto라는 일급컬렉션으로서 할 수 있는 역할이 무엇이 있을까요?

### 2. randomNumbers 범위 보장?

```kotlin
class Lotto(val randomNumbers: List<Int>) { ... }
```

> randomNumbers의 각 원소들이 1~45 사이에 들어간다는걸 확신할 수 있을까요?
> 모든 원시 값과 문자열을 포장한다

→ 함수명 `randomNumbers`로는 도메인 invariant 보장 못함. *LottoNumber* 도메인 객체 필요.

## 얻은 교훈

- **Lotto 도메인 invariant = 개수 + 범위 + 중복**. 셋 모두 init에서 강제.
- **변수명만으론 invariant 보장 못함** → 타입 시스템 + 도메인 객체.
