### 2. bonus 확인에 map 불필요

```kotlin
val bonusInLotto = lotto.lottoNumbers.map { it.number }.contains(bonusNumber.value)
```

> bonusNumber가 있는지 확인하기 위해, map으로 변환할 필요는 없습니다. 앞서 사용한 `count { ... }` 함수를 잘 활용해보세요

### 3. 같은 클래스 파라미터는 private 함수 호출 가능

> 위 함수에서 `lotto.lottoNumbers.map` 함수는 몇번이 호출이 될까요? 메소드의 파라미터로 같은 클래스가 들어온다면, private 함수를 호출할 수 있습니다.

## 얻은 교훈

- **같은 클래스끼리 = private 호출 가능**. `Lotto.match(other: Lotto)` 안에서 `other.numbers` 직접 접근 OK.
- **`count {}`로 한 번 순회** — `map().contains()`처럼 두 번 순회 회피.
