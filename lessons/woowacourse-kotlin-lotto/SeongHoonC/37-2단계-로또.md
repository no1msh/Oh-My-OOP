### 2. `repeat` 이름의 혼동

```kotlin
fun repeat(...) { ... }
```

> 반복이 된다는 것은 '외부'의 기준이지, 현재 함수 내부에서는 반복작업이 이루어지지 않으므로 repeat 이라는 이름은 혼동을 줄 수 있지 않을까요?

→ 함수 이름은 *함수가 무엇을 하는지*이지 *호출자가 어떻게 쓰는지*가 아님.

## 얻은 교훈

- **함수명 = 함수 내부 행위**. `repeat`은 함수 내부에서 반복할 때만 의미.
