## 얻은 교훈

- **`!!`은 *Kotlin null safety 무시*** — *마지막 수단*.
- **재활용 가능 객체 *매번 new X*** — *상태 없는 협력자*는 *한 번 만 생성 + 재사용*.
- **결과 생성 *책임 위치*** = *결과 객체*에.
- **`delegation` *전체 인터페이스 노출* vs *일급 컬렉션 선택 노출***.
- **`List(n) { gen() }`** — 모든 PR 공통.
- **`Count` *이름에 비해 많은 의존*** = 책임 모호.
- **에러 메시지 *정확*** — *로또 숫자 ≠ 당첨 번호*. 어휘 정합.
- **`ParameterizedTest` *경계값/시나리오 분리* + `MethodSource` *복잡 객체*** + **given 단계 분리** — 테스트 가독성 3박자.
- **`asSequence`** — *지연 평가*. *대량 컬렉션 변환 체이닝* 시 메모리 효율.
- **`fun interface` 람다** — *SAM*.
- **`given/when/then` *짧은 테스트도*** — *읽기 가독성*.
- **`assertThat(Collection).hasSize()`** = assertj idiom.
