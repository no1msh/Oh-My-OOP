## 얻은 교훈

- **LottoNumber 추출의 진짜 가치 = *호출처가 의심하지 않게***. 외부에 `Int` 노출 = 매번 "이게 로또 번호 맞나?" 의심. 타입이 정답.
- **enum 필드의 분류 — *속성* vs *검색 키***. `matchBonus`는 Rank가 *되는 조건*이지 *Rank의 본질 속성*이 아님. enum 필드는 *영구한 속성*만.
- **MISS/NONE fallback > Exception**. enum이 전 케이스를 표현하면 *예외 던질 일 없음*. `find { ... } ?: MISS`.
- **TDD 커밋 단위 = "다른 사람이 리뷰 가능한 단위"**. 테스트만 있는 커밋은 빌드 실패. 둘을 합치면 *완결된 기능*.
