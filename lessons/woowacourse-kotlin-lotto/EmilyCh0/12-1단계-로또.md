### 7. *given/when/then*

리뷰어: "*테스트 케이스 구현부의 가독성도 중요*해요! *준비, 실행, 검증을 나눠서 구현*해 보면 어떨까요?
```kotlin
// given
private val testLotto = Lotto(setOf(1, 2, 3, 4, 5, 6))
private val winningLotto = WinningNumbers(setOf(1, 2, 3, 4, 5, 6), 7)
// when
val actual = testLotto.getLottoResult(winningLotto)
// then
assertThat(actual).isEqualTo(LottoResult.FIRST)
```
*저는 given, when, then 표기법을 즐겨 사용*합니다!"
