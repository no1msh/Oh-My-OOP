## 핵심 지적

### 1. PurchaseAmount 만들었지만 Int 반환

```kotlin
class PurchaseAmount(val value: Int) { ... }
fun calculateCount(amount: PurchaseAmount): Int = amount.value / PURCHASE_UNIT  // ⚠ Int 반환
```

> PurchaseAmount 클래스를 만들어주셨는데, Int 타입을 리턴해주게 된다면 해당 클래스를 사용하는 의미가 반감될 것 같아요.

→ `PurchaseAmount.numberOfLottos(): LottoCount` 같이 도메인 타입 유지.
