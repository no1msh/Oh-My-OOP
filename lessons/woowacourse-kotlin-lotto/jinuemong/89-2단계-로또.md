### 2. `TreeSet` 사용 이유?

> Set 이 아닌 TreeSet 타입으로 선언해주신 이유가 있을까요?

→ TreeSet은 정렬 자동. 그 의도가 필요한지 명시.

### 3. `prize > 0`인데 charge가 0 = 비정상

> 우리는 수익률을 구해야하고, prize 값이 온전한 상황일 때 charge 가 0 으로 전달이 된다면, 이는 비정상적인 상황이기 때문에 예외를 던지는 것이 더 적절하지 않을까요?

→ 비정상 상태 = 예외. 0 같은 sentinel 반환 X.

## 얻은 교훈

- **`Verifier` 모호 = 무엇을 검증하는지 명시**.
- **자료구조 선택 = 의도 명시** — TreeSet (정렬), HashSet (중복 제거), LinkedHashSet (삽입 순서).
- **비정상 상태 = 예외 정당화**. *논리 오류*는 예외 던지기 적절.
