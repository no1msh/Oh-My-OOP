## 얻은 교훈

- **`Verifier`/`Validator` god-name** = *책임 비대*. PR #25, #50 동일.
- **`TreeSet` *의도 명시*** — *정렬 필요*면 명시, 단순 *Set 의미*면 `HashSet`/`LinkedHashSet`.
- **비정상 = *예외*** — *논리 오류*는 *sentinel 반환*보다 *예외*가 *디버깅 가능*.
- **`Message` *View 패키지*** — UI 어휘는 *Domain/util* X.
- **함수 *호출 순서 의존 = 시간 결합***. *순서가 invariant*면 *명시 또는 통합*.
- **수동/자동 *내부 구분 X*** — *Lottos*는 *발급 후 동등*. *입력 시 분기*만.
- **`List` *size 비교* ≠ 중복 검증** — *자료구조*가 *invariant 표현*. `Set`이 자연.
- **리턴 타입 *인터페이스*** — *Liskov*. *구체 구현체* 노출은 *호출자 결합*.
- **검증/예외 *분리 클래스* = 또 다른 Controller** — 도메인이 *자기 검증*. PR #25, #50, #113 동일 패턴.
- **`ManualLottoCount` *역할 드러나는 네이밍*** — `Count`보다 *수식어 + Count*.
- **`run` *함수 분리 적정 단위*** — PR #131 *분리 vs 분해* 경계.
