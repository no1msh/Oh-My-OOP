### 2. `insertCostMessage` — insert의 주체?

```kotlin
fun insertCostMessage() { println("...") }
fun showResultMessage() { println("...") }
```

> `insertCostMessage` 라는 네이밍에서 insert 의 주체는 누구일까요? `show` 와 `insert` 각각의 케이스가 있는데 네이밍을 붙히신 기준이 궁금합니다.

→ `insert`는 *값을 넣는* 행위. View가 *보여주는* 함수는 `show`/`print`. 동사 일관성.
