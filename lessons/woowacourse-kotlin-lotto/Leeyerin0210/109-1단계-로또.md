## 얻은 교훈

- **"일급 컬렉션"의 정확한 용어** — Object Calisthenics 9번째 룰. `List<T>` 그대로 노출 회피 + 컬렉션 자체에 도메인 행위 부여.
- **`intersect()` 활용** — lotto 매칭 표준 함수.
- **Lotto의 관심사 = 자기 번호**. 외부 (보너스, 당첨 기준) 비교는 *그 도메인이 시키는 일*.
- **Lint 설정 + IDE 설정 일관화** — 충돌하면 매번 lint 수정 부담.
