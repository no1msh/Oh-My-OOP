## 핵심 지적

### 1. 콘솔 `1,2,3,4,5,6` 입력 시 에러

> 실제로 콘솔에 1,2,3,4,5,6 을 입력하면 에러가 발생하고 있어요!

### 2. `LottoNumber` 미추출 + `Lotto` 비대

> 1~45를 갖는 [로또번호] 라는 객체를 갖게 된다면 조금 더 감이 올 것 같은데요, 당첨 로또를 계산하는건 "당첨 로또" 라는 객체를 생성하여 책임을 분리할 수 있을 것 같아요. 현재 Lotto 객체가 너무 많...

### 3. 1-45 범위 확신 불가

> 현재 구조에서는 numbers의 각 원소들이 1~45 사이에 들어간다는걸 확신할 수 있을까요? 아마 Lotto의 초기화 부분을 보지 않는다면 해당 원소가 1..45에 해당함을 쉽게 알지 못할겁니다.
