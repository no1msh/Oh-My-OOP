### 8. `runCatching` 패턴 — *두 함수 반복*

```kotlin
fun inputPurchasePrice(): String? {
    return runCatching {
        val input = readln().also { InputValidator.ValidateNumber(it) }
        input
    }.getOrNull()
}

fun retryInputPurchasePrice(): String {
    var input: String? = null
    while (input == null) { input = inputPurchasePrice() }
    return input
}
```

학생: "runCatching을 활용해 잘못된 값 입력 시 재입력을 받을 수 있도록 코드를 작성. 하지만 하나의 입력값을 검증할 때마다 두 개의 함수 형식이 반복되는 것이 어색." → 학생이 *유틸리티 함수*로 추상화. 리뷰어: "프로그램 내에서 반드시 필요한 값이라면 `fun inputWinningNumbers(): Set<Lotto> { val input = inputView.inputWinningNumber() ?: inputWinningNumbers() }`."

## 리뷰어 의견 요지

1. **`LottoNumber` 분리 = 범위 검증을 타입에 위임** — Lotto는 *크기*만 검증.
2. **자료구조 = invariant 표현** — Set이 *중복 불가*를 *타입에 새겨줌*.
3. **객체명 = *객체 자체의 역할*** — *사용자 관점 명사*는 도메인 어휘 부재 신호.
4. **`Purchase`가 String을 받으면 도메인이 *입력 형식*을 알게 됨** — 변환은 어딘가 *외부*.
5. **랜덤 의존은 *함수형 인터페이스*로 상위 주입** — TDD 정합성.
6. **`runCatching`은 *재시도+null* 양쪽 가능** — 두 함수 반복 시 *유틸리티*로 추상.
7. **null의 의미** — "이 값을 만들 수 없다." 호출자가 *다음 행동*을 결정.
8. **리뷰 반영 = 명시적 확인** — push 누락도 흔한 실수.
9. **Tell, Don't Ask** — `WinningLotto(inputView.inputWinningNumber())` 한 줄로.
10. **2인승 자동차 비유** — *자료구조 선택*이 *제약을 외부에 친절하게 알림*.

## 얻은 교훈

- **`LottoNumber` 분리**는 *범위*를 타입에 위임 — Lotto는 *크기* 검증만, *각 번호의 유효성*은 LottoNumber.
- **자료구조 선택 = invariant의 *외부 알림*** — `Set<LottoNumber>`이면 호출자가 *중복 불가*를 즉시 인지.
- **객체명은 *역할*** — `Purchase`(행위)보다 `PurchaseAmount`(값) — *명사형*이 객체의 정체성에 더 가까움.
- **도메인이 *입력 형식*을 알면 결합** — `Purchase(amount: String)`이면 *입력 형식 변경*이 도메인 변경.
- **`runCatching`의 *두 표정***  — `.getOrNull()`로 null화, `.getOrElse { retry() }`로 재시도. *어느 표정*이 적절한지 호출 위치에서 결정.
- **null의 의미는 *값 부재*** — *재시도/기본값/실패*는 호출자가 결정.
- **`fun interface`** = SAM 람다 주입의 표준 — *생성 알고리즘*을 외부에서.
- **2인승 자동차 비유** — *제약을 사후 검증*이 아니라 *타입으로 외부에 친절히* 알림.
- **`data class` = `equals`/`hashCode`/`toString` 자동** — *참조 비교*가 아니라 *값 비교* 의도면 data class. 단, *Flyweight*와 결합하면 정합성 점검 필요.
- **TDD 정합성 = 핵심 로직이 테스트 가능** — 랜덤이 *핵심*인 객체가 *테스트 불가*면 그건 TDD가 *아닌* 것.
- **리뷰 반영 = *push 후 재확인*** — 커밋만 하고 push 안 하면 리뷰어가 *반영되지 않음*으로 봄.
