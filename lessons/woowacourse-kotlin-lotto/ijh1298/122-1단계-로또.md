## 학생 자가 의문

### 1. enum의 역할 — 열거만 vs 데이터 보유

> enum class는 이름에 맞게 열거만 하는 역할을 하는 것이 좋을까요? 프리코스에서 이 미션을 진행할 때는 Rank 클래스의 프로퍼티로 이 Rank에 해당하는 당첨 개수를 가지도록 두었습니다.

→ enum이 데이터 보유 = OOP 본연. 단순 열거는 java idiom.

### 2. 일급 컬렉션 단지 toString 위해?

> 단지 toString을 오버라이드 하기 위한 일급 컬렉션 사용에 대해 어떻게 생각하시나요?

→ toString만 위한 일급 컬렉션 = 약한 정당화. 검증 + 행위 둘 다 있을 때.

## 얻은 교훈

- **enum + 데이터 + 행위** = Kotlin OOP에서 자연스러움. 자바식 *단순 열거*만 쓰는 건 의도 잃음.
- **일급 컬렉션의 정당화 = 검증 + 행위 둘 다**. toString만이면 일반 class도 충분.
