### 2. Result.entries.find 두 번

```kotlin
Result.entries.find { ... } ?: Result.entries.find { ... } ?: MISS
```

> 이 부분을 조금 더 최적화 해볼 수 있을 것 같아요. Result.entries.find를 두번 쓰지 않고 한번만 사용해도 될 것 같아요

### 3. Map 일괄 생성 — groupingBy

> Result를 Key로 가지는 Map을 만들고 하나씩 찾아서 넣지 않고, 한번에 만들어 볼 수는 없을 까요?

→ `groupingBy { ... }.eachCount()`.
