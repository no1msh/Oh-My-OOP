## 핵심 지적

### 1. 테스트 항목과 코드 불일치

```kotlin
@Test fun `1~45 사이의 숫자인지 검증`() {
    assertThrows<...> { LottoNumber(0) }
    assertThrows<...> { LottoNumber(46) }
}
```

> 테스트 항목은 로또 번호가 `1~45`의 숫자인데 실제 코드는 `1~45`의 숫자가 아닌, 0과 46의 경계에 대한 테스트네요!

→ 두 테스트로 분리: 정상 케이스 + 경계 외 케이스.

### 2. secondary constructor (Fake Constructor) 도입

```kotlin
Lotto(setOf(...).map{}.toSet())  // 반복
```

→ `Lotto(1, 2, 3, 4, 5, 6)` 같은 fake constructor.

## 얻은 교훈

- **테스트 함수명 = 검증 *결과*까지**. "1-45인지 검증" → "1-45 범위 밖이면 예외" + "1-45 범위 내면 정상".
- **secondary/fake constructor** — 테스트 가독성.
