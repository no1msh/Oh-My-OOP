## 못한 점 + 핵심 지적

### 1. View 인스턴스를 Controller 지역 변수로

```kotlin
class LottoController {
    fun run() {
        val inputView = InputView()  // ⚠ 지역 변수
        val outputView = OutputView()
        ...
    }
}
```

> inputView 와 outputView을 지역변수로 선언하신 이유가 궁금합니다!
> 1. 구현할 수 있는 다른 방법은 어떤 것이 있을까요??
> 2. 현재 방법대로 구현을 했을 때는 어떤 단점이 존재할까요??

→ 생성자 주입 또는 object. 지역 변수 = 매 호출마다 생성, 테스트 시 fake 교체 불가.
